# resource/ —— 本地音乐目录（分类由 playlist.txt 记录）

本目录存放**本地音频文件**；**分类不再用子目录表示**，而是记录在同目录的 `playlist.txt` 里。

## 目录示意

```
resource/
├── playlist.txt     ← 音乐清单：分类 + 文件路径（+ 歌名/歌手/专辑/歌词）
├── pop-1.wav
├── pop-2.wav
├── rock-1.wav
├── classical-1.wav
├── electronic-1.wav
├── light-1.wav
└── ...              ← 所有音频平铺放在这里
```

## playlist.txt 格式

```
# 以 [分类名] 作为分组标题，下面每行一首歌
# 每行： 文件路径 | 歌名 | 歌手 | 专辑 | 歌词
[流行]
resource/pop-1.wav | 夏日气泡 | 林小夏 | 夏日限定 | 阳光落在汽水的气泡里\n我们随节奏轻轻摇晃
resource/pop-2.wav | 星空告白 | 陈予安 | 星河 | 把整片星空都送给你

[摇滚]
resource/rock-1.wav | 逆风燃烧 | 铁轨乐队 | 燃烧吧 | 迎着逆风我绝不后退
```

规则：
- `[分类名]` 是分组标题，其下每行一首歌；
- 每行字段用竖线 `|` 分隔：**只有「文件路径」必填**，歌名/歌手/专辑/歌词可留空（歌名留空则用文件名）；
- 以 `#` 开头是注释，空行会被忽略；
- 歌词里要换行，用 `\n` 表示；
- 想加分类：加一个 `[新分类名]` 段落即可；想加歌：在对应分类下加一行。

## 怎么换成自己的音乐？

1. 把你的音频（mp3/wav 均可）放进本 `resource/` 目录；
2. 打开 `playlist.txt`，在相应分类下写一行指向它，例如：
   ```
   [流行]
   resource/我的歌.mp3 | 我的歌 | 歌手名 | 专辑名 | 第一句歌词\n第二句歌词
   ```
3. 刷新页面即可看到。**全程不需要改 app.js，也不用建子目录。**

> 说明：页面必须通过 HTTP 服务打开（例如本项目的 `python3 tools/serve.py 8080`），
> 因为清单是用 fetch 读取的，直接双击 html 以 file:// 打开会被浏览器安全策略拦截。

## 在页面里"移动分类"

歌曲列表每行右侧、底部播放条、以及播放详情页的控制按钮旁，都有「⇄ 移动」按钮：
点击后选择一个目标分类，即可把这首歌移到该分类。

- 通过 `python3 tools/serve.py 8080` 打开时：移动会**写回本文件 playlist.txt**（真正持久化，
  刷新后依然在目标分类；注意移动后该歌会排到目标分类末尾）。
- 若用别的纯静态服务器托管（没有 `/api/move`）：移动只在**当前浏览器会话内**生效，
  刷新后会还原，页面会提示"未能写入 playlist.txt"。
