# resource/ —— 本地音乐目录

本目录存放**本地音频文件**。分类不再靠子目录区分，而是由 `playlist.txt` 记录；**但 `playlist.txt` 是可选的**。

## 目录示意

```
resource/
├── playlist.txt      ← 可选：音乐清单（分类 + 文件路径 + 歌名/歌手/专辑/歌词）
├── audio-list.json   ← 自动生成：音频清单（纯静态托管时用于“自动识别”）
├── pop-1.wav
├── rock-1.wav
├── classical-1.wav
└── ...               ← 所有音频平铺放在这里
```

## 核心特性

### 1) 自动识别新音频（未分组）

把音频文件（mp3/wav/ogg/m4a/flac…）直接丢进本目录：

- 用 `python3 tools/serve.py 8080` 打开时：服务端 `/api/list` **实时扫描**，新文件立刻出现，归入「**未分组**」。
- 纯静态托管（如 GitHub Pages）时：播放器读取构建期生成的 `resource/audio-list.json`。
  加了音频后重跑一次：`node tools/scan-audio.mjs`，新文件即出现在「未分组」。

播放器逻辑：清单里**已登记**的音频按清单分类显示；**没登记的**自动进入「未分组」。

### 2) 播放列表是“可选”的

- 有 `playlist.txt`：按其分类展示。
- **没有 / 读取失败**：资源目录里的**所有音频**都放进「未分组」，照样能播。

`playlist.txt` 格式：

```
# [分类名] 作为分组标题，下面每行一首
# 每行： 文件路径 | 歌名 | 歌手 | 专辑 | 歌词
[流行]
resource/pop-1.wav | 夏日气泡 | 林小夏 | 夏日限定 | 阳光落在汽水的气泡里\n我们随节奏轻轻摇晃
```

- 只有「文件路径」必填，其余可留空（歌名留空则取文件名）；
- 字段用竖线 `|` 分隔；`#` 开头是注释；歌词换行用 `\n` 表示。

### 3) 新建分组 / 移动歌曲

- 分类页右上角「**＋ 新建分组**」可创建自定义分组。
- 歌曲列表、底部播放条、播放详情页都有「⇄ 移动」，可把歌曲移到任意分组。
- 分组与移动通过浏览器 localStorage（键 `mp-groups-v1`）持久化，**纯静态托管下刷新也保持**（同一浏览器）。
- 若通过 `serve.py` 运行，移动还会额外尝试写回 `playlist.txt`（走 `/api/move`）。

> 说明：纯静态托管（无后端）时，无法把播放器里的分组改动写回服务器文件，跨设备不同步；
> 这是本地存储的固有限制。用 `serve.py` 则移动可写回 `playlist.txt`。

## 换成自己的音乐

1. 把音频放进本 `resource/` 目录；
2. （可选）在 `playlist.txt` 里登记分类与元信息；不登记就会自动进「未分组」；
3. 纯静态托管时重跑 `node tools/scan-audio.mjs` 更新 `audio-list.json`；用 `serve.py` 则无需此步；
4. 刷新页面即可。
