# 安装步骤

## 环境要求

- 现代浏览器（Chrome / Edge / Firefox / Safari）
- 可选：Python 3 或任意静态文件服务器

## 安装流程

1. 获取本项目代码
2. 用静态服务器打开 `index.html`
3. 页面会**默认读取 `resource/` 目录**

> 无需数据库、无需后端，纯前端运行；所有文件都在你的浏览器里读取，不会上传。

## 常见问题

- **页面空白？** 请通过 `http(s)://` 打开；直接双击 `file://` 无法读取目录列表，此时会回退到内置示例。
- **图片不显示？** 确认图片相对路径相对于所在 Markdown 文件是正确的。

~~~js
// 判断是否为 Markdown 文件的小工具
const isMd = (name) => /\.(md|markdown|mdx)$/i.test(name);
~~~
